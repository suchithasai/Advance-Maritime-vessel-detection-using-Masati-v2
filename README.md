# Advanced Maritime Vessel Detection using Masati-v2
Advanced Maritime Vessel Detection using the MASATI-v2 dataset and YOLOv10 for accurate vessel identification in satellite imagery. The project leverages deep learning and data augmentation techniques to enhance detection performance, achieving high precision for real-time maritime surveillance applications.

Datasat Link : https://www.kaggle.com/datasets/louisaberdeen/masati-v2
